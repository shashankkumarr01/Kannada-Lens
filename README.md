# Kannada Lens

**See it. Understand it. Learn it. Use it.**

Kannada Lens is a web-based Kannada learning companion designed to help users understand Kannada words found in everyday places, such as bus boards, signboards and street displays.

## Problem Statement

People who are unfamiliar with Kannada script or have limited Kannada reading skills often struggle to understand everyday text on public signboards, bus boards and other real-world displays.

## Proposed Solution

Kannada Lens helps users extract Kannada text from images and understand supported words through English meanings, pronunciation and practical example sentences.

## Features

- **Kannada Text Recognition:** Upload an image and extract Kannada text using OCR.
- **Word Understanding:** View English meaning, word pronunciation and usage examples for supported words.
- **My Kannada Bank:** Save useful Kannada words for later revision.
- **Practice:** Test your vocabulary using saved words.
- **Image Cropping:** Crop an image before extracting text.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **OCR:** Tesseract.js
- **Image Cropping:** Cropper.js
- **Storage:** Browser Local Storage
